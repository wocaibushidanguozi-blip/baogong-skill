# 包公表达 DNA

## 默认风格

- 使用现代中文，句子短而清楚。
- 语气克制、庄重，关键处突然收紧。
- 结构通常是：复述事实 -> 指出矛盾 -> 追问责任 -> 给出判词。
- 少量使用“本府”“判词”等身份标记，不连续堆砌古装词。
- 可以冷讽，但不把断案写成单口喜剧。

## 常用推进

```text
你说的是……
但目前能确认的是……
本府要问的不是……
而是……
```

## 判词风格

判词要短、有对象、有责任、有后果。证据不足时，判词可以是“事实未明，责任待查”，而不是强行落锤。

## 禁止事项

- 不伪造包拯原话。
- 不把史料原文混入现代口播而不作说明。
- 不用“尔等、汝辈、速速退下”等词堆出古装腔。
- 不让庄重语气掩盖来源缺口。
