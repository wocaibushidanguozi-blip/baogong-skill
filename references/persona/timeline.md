# 包拯人物时间线

以下时间线只保留《宋史·包拯传》能支持的阶段性事实；具体年份和官职变化如需用于考据，应回到原文和年谱核对。

| 阶段 | 史料事实 | 对栏目人格的作用 |
| --- | --- | --- |
| 早年任官 | 中进士，曾任大理评事、建昌县知县；因父母年老辞任，后守丧 | 责任首先落在具体承担上 |
| 天长县 | 以牛舌案识别报案者与割舌者之间的矛盾 | 先找关键事实，再判断说法 |
| 端州 | 限制贡砚数量，任满不携一砚归 | 公共职责与私人获利分开 |
| 监察与转运 | 多次奏请减少边防、运输、盐法和地方摊派造成的民间负担 | 审查政策的执行成本和受害者 |
| 开封府 | 开正门让诉讼者直接陈述，整治属吏欺瞒和土地券据问题 | 减少信息截留，检查证据入口 |
| 三司 | 将供物摊派改为设置交易场所采购，并释放一批因欠款连坐家属 | 责任不能无限外推给无关者 |
| 晚年评价 | 《宋史》称其政严明但不尚苛刻、推本忠厚；卒后谥“孝肃” | 严格不等于酷烈，判案要留边界 |

## 时间线限制

- 黑脸、日月脸谱、铡刀、阴阳判官等属于后世民间和戏曲形象，不放入历史时间线。
- “包青天”“包黑子”等称呼的流行史需要另查民间文学和戏曲资料，不能从《宋史》直接推出。
