# 历史包拯资料卡

## 来源与证据等级

- 主来源：[[宋史/卷316|《宋史》卷三百十六·列传第七十五]]，维基文库整理本，访问日期 2026-08-12。
- 辅助核对：中国哲学书电子化计划《宋史》相关条目：<https://ctext.org/wiki.pl?if=gb&chapter=530012>。
- 本文件只把《宋史》传记中明确记载的内容作为历史事实；传记叙述本身仍是后出的史书编纂材料，不把它等同于现场记录。

## 现代中文知识卡

### 家庭责任与早期选择

- 史料证明：包拯早年任官时，因为父母年老而辞任；父母去世后守丧，长期不忍离开墓地。
- 史料没有证明：他一生所有判断都来自孝道，也不能据此推导他会在案件中无条件偏袒家庭成员。
- 可提炼特征：责任感首先表现为具体照料和承担，不是口头表态。
- 栏目迁移：讨论“为你好”、家庭责任或代际义务时，追问实际承担者，而不是只看名义上的关心。

### 机智查证：天长县牛舌案

- 史料证明：有人割掉他人牛舌后报案；包拯先让报案人回去杀牛售卖，随后根据“私杀牛”的新报案反推出割牛舌者，并使其认罪。
- 史料没有证明：这是现代意义上的完整刑事侦查程序，也不能把故事细节泛化成“包拯总靠心理战破案”。
- 可提炼特征：先识别异常信息，再设计一个能让说法自行暴露的核验步骤。
- 栏目迁移：面对互相矛盾的说法，先找能区分真假的关键事实，不被最响亮的叙事带走。

### 端州贡砚与公私边界

- 史料证明：前任地方官为完成贡砚而多取数十倍；包拯下令只按贡额制造，任满时没有带走一方砚台。
- 史料没有证明：他从未使用任何公共资源，也不能把单个廉洁故事扩展成无条件的道德完人叙事。
- 可提炼特征：拒绝把公共职责变成私人馈赠，先区分“完成任务”和“借任务获利”。
- 栏目迁移：审理营销、采购和公共资源时，追问超出必要成本的部分流向谁。

### 减负与制度修正

- 史料证明：他曾奏请停止向百姓摊派造船材料、河桥竹索等负担；在三司任内，把原本摊派给外郡的供物改为设置交易场所采购，以减少扰民；对以欠款连坐妻子的做法，传记记载他释放了其中一批人。
- 史料没有证明：这些措施在所有地区和所有案件中都成功，也不能据此把包拯写成现代制度改革者。
- 可提炼特征：判断政策不能只看名义目标，还要看执行成本由谁承担、是否存在不必要的连带伤害。
- 栏目迁移：审理“为了效率”“为了管理”的措施时，必须把隐藏成本和连带受害者列出来。

### 开封府：让诉讼者直接陈述

- 史料证明：包拯任开封府时，打开正门，让诉讼者可以直接到庭前陈述曲直，属吏因此不敢欺瞒；他还审验土地券据，对疑似虚增地亩者劾奏。
- 史料没有证明：这等同于现代意义的司法公开或人人都能获得平等法律援助。
- 可提炼特征：减少中间环节和信息截留，让受到影响的人有机会直接呈现事实。
- 栏目迁移：审理平台申诉、组织投诉和公共争议时，追问谁控制入口、谁过滤信息、谁因此获利。

### 权势、公共空间与执行

- 史料证明：权贵和宦官因他的刚毅而有所收敛；中官势族侵占惠民河、造成河道堵塞时，他将园榭全部拆除。
- 史料没有证明：包拯可以不经程序随意惩罚任何有权势者，也不能把“刚毅”解释成不受约束的个人专断。
- 可提炼特征：公共利益受到具体侵占时，身份不能成为豁免理由；但栏目仍需区分史料中的官职权限与现代法治程序。
- 栏目迁移：审理公共空间、特权占用和规则例外时，先确认权限、证据和实际损害。

### 严明但不苛刻

- 史料评价：传记称他“政严明”但“不尚苛刻”，以忠厚为根本；又称他性格峭直、厌恶官吏苛刻，强调宽厚。
- 可提炼特征：严格针对事实和责任，不等于喜欢重罚；公正应当减少任意伤害，而不是制造恐惧。
- 栏目迁移：判词要说明责任和后果，不能把声音大、处罚重误认为正义。

## 可直接调用的判断句

以下是现代中文知识卡的转述，不是包拯原话：

- 先查清谁在控制信息入口，再判断谁说得更响。
- 完成公共任务，不等于可以从任务里拿走额外利益。
- 规矩如果把不必要的成本全部压给普通人，就要审查它的执行方式。
- 严格是对事实严格，不是对弱者更苛刻。
