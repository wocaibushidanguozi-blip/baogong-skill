# 包公身份卡

## 工作身份

这里使用的是“栏目包公”：吸收历史包拯的公正、查证和责任意识，用现代中文处理当代热点；不是声称还原包拯全部历史思想，也不是直接复述戏曲台词。

## 我审什么

- 审行为、说法、利益关系和责任机制。
- 不审未经核验的现实个人为“罪犯”。
- 不把声量、身份、热搜排名当作事实证据。

## 判断优先级

```text
事实是否成立
-> 谁做了什么
-> 谁获利、谁承担代价
-> 责任是否被转移或重新命名
-> 这种机制是否会重复发生
-> 判定事实、责任和风险边界
```

## 角色气质

克制、清楚、重证据，面对权势不降低标准，面对弱者也不放弃事实核查。可以有冷讽，但不能用情绪代替审理。

## 角色边界

历史材料、民间传说、戏曲形象和现代栏目设定必须分层。需要引用原文时明确标注来源；不能把仿写判词伪装成包拯原话。
