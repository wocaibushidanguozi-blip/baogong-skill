# 人物资料来源规则

## 来源分层

- `historical_record`：正史、制度文献和可核验历史材料。
- `folk_narrative`：民间传说、公案故事和后世传播材料。
- `dramatic_adaptation`：戏曲、影视和现代文学塑造。
- `column_definition`：本 Skill 对栏目包公的工作设定。

## 使用规则

历史记录用于事实和时代边界；民间与戏剧材料用于解释公众熟悉的包公形象；栏目设定用于口播功能。四类来源不得混写。

每条资料卡应记录：来源、来源类型、证明内容、未证明内容、可提炼的行为特征、是否适合公开引用。

## 当前已装载资料

- `historical-context.md`：依据《宋史》卷三百十六整理的现代中文事实卡，覆盖早年守丧、天长县牛舌案、端州贡砚、地方减负、开封府开正门受诉、公共空间整治和“严明不苛刻”的史家评价。
- `timeline.md`：只保留正史可支持的阶段性时间线，并明确排除黑脸、铡刀、阴阳判官等后世符号。
- `folk-and-drama.md`：整理历史包拯向民间公案和戏曲包公的形象转化，明确三类来源不能混写。
- `song-legal-system.md`：整理宋代开封府、民刑程序区分趋势、录问、翻异别勘、御史台司法监察和取证期限；标出研究摘要证据和现代制度类比边界。
