# 摘要阶段

## 目标

只处理用户选中的标题。先寻找原始材料，再输出短摘要；不生成完整断案稿。

## 流程

1. 固定事件名称、人物/主体、时间和地点。
2. 查找原始采访、完整视频、公开文件、当事人声明或多来源印证。
3. 区分已确认事实、待核实说法和评论性判断。
4. 标记平台风险和是否适合进入断案阶段。

## 输出

```text
选题编号与原标题
一句话摘要
已确认事实：最多 3 条
未确认说法
来源列表与证据等级
风险状态：通过/条件通过/待核实/排除
可审理对象：行为/说法/机制
下一步：是否进入素材/断案；若进入素材，说明需要抓取的原话截图、短视频或来源页面
```

如果只有标题或二手报道，不补写新闻细节；输出待补充的具体来源。

如果选题属于 `internet_discourse` 或 `long_term_mechanism`，且没有单一原始事件，不要为了进入断案而标记为普通“通过”。标记为“条件通过”，后续只能生成话语/机制分析所需的素材包和文案。

摘要必须额外输出“来源追踪链”：

```text
已知触发材料 -> 二手转述者 -> 被转述对象 -> 原始来源 -> 当前锁定状态
```

没有原始来源时，明确标记 `source_lock_status: unlocked`，并把下一步设为“追踪来源”，不能直接要求素材阶段抓取相似视频。
